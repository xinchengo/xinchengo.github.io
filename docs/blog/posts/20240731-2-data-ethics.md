# 简单的数据伦理学

这是 *Deep Learning for Coders with fastai and PyTorch AI Applications Without a PhD (Jeremy Howard, Sylvain Gugger)* 第三章 *Data Ethics* 的学习笔记。

书的本章简要地介绍了数据伦理学 (data ethics) 以及深度学习者需要注意的一些问题。

<!-- more -->

由于对这个领域不是很熟悉，下面的笔记只是本着试着理解、熟悉概念而写的，可能包含很多错误。


## 问题

### 数据伦理的重要性

首先的一个问题是对于深度学习开发者而言，为什么一定要考虑数据伦理问题？为什么数据伦理不仅仅是产品经理需要考虑的问题呢？数据伦理的重要性可以从以下角度得到阐释：

- 如果忽视数据伦理，可能造成严重的灾难；为了防患于未然，每个人都有责任让数据、算法不被滥用。
- 深度学习开发者对人工智能模型的各种参数和细节**理解最深**，只有他们才能在底层上规范大模型的行为，保护每个人的权利。

### 数据伦理的主要主题

数据伦理学的主题主要有：

- 追索和问责制的需求 (the need for recourse and accountability)
    
    复杂的系统缺乏责任主体，当问题发生时，各方总是以各种理由推卸责任。比如，当阿肯色州的医疗系统算法的一个 Bug 让脑瘫患者得不到医疗服务时：

    ```mermaid
    flowchart LR
        A(算法的发明人)
        B(政府官员)
        C(实现算法的人)
        A -->|推卸责任| B
        B -->|推卸责任| C
    ```

    对于从事机器学习的人，我们需要考虑自己的算法将如何被用于实际，思考可能产生的不好后果，积极承担社会责任

- 反馈循环 (feedback loops)

    这点比较类似生物学中的“正反馈调节”。比如，某视频网站平台的智能推荐算法曾经使得阴谋论 (conspiracy theory) 和极端主义 (extremism) 内容经常被推荐。这一现象又导致了**信息茧房** (information cocoon)，具体的反馈循环过程如下：

    ```mermaid
    flowchart LR
        A(人们容易被争议内容吸引)
        B(阴谋论视频经常被视频网站推送)
        C(阴谋论者常常花较多时间看网上视频)
        D(阴谋论者逐渐沉迷视频网站)
        E(越来越多人相信阴谋论)
        A-->B
        C-->D
        B-->D
        D-->B
        B-->E
        E-->B
    ```

    反馈循环产生问题的一个原因是衡量算法的标准，一个算法如果仅仅以经济效益作为优化的标准，那么它会做一切能够带来收益的事情。这样的算法在大的方向上可以完成既定的任务（比如将视频推荐给可能对它感兴趣的人），但在有些时候，它也会带来意想不到的糟糕结果（比如助长了阴谋论的传播）。

- 偏见 (bias)

    机器学习在数据上，训练的方式上存在一些偏见，具体在论文 [*A Framework for Understanding Sources of Harm throughout the Machine Learning Life Cycle*](https://dl.acm.org/doi/fullHtml/10.1145/3465416.3483305) 有阐释。


### 各种偏见（偏差）

- 历史 (historical) 偏见：由于人们具有偏见和社会的不公平导致的偏见

    比如，由于经济和历史原因，图片数据集往往大多数都来自欧美，由它们训练出的模型对其他地区物品的识别效果欠佳。

- 测量 (measurement) 偏见：模型测量的事物，与我们想要测量的标准不同，导致的偏差。
    
    比如，我们想要模型分析导致中风的原因，模型却分析出了**到医院就诊的中风病人**常常具有的特点（比如有足够来看病的钱）。

- 聚合 (aggregation) 偏见：整理数据的方式不能反映真实的数据导致的偏差。

    比如，糖尿病的研究常常忽略了族裔，性别的因素，但是不同族裔的人群糖尿病并发症的种类有着明显的区别，糖化血红蛋白 (HbA1c) 的水平与族裔和性别也有着复杂的联系。忽略了这两个因素整理数据，是得不到正确的诊断方法的。

- 表征 (representation) 偏见：样本不具有代表性，导致的偏差。

    机器学习算法会**放大** (amplify) 这种偏差。

### 为什么算法的偏见比人的偏见更可怕

1. 机器学习可能产生反馈循环：微小的偏见可能因此疯狂的增长
2. 机器学习算法会放大偏见：人们的偏见能给机器学习带来更大的偏见
3. 在人们的印象中，算法往往是公平、客观的，人们对算法缺乏防备心理
4. 机器学习算法往往缺乏手动调节的方法——即使偏见被发现，开发者也很难简单地手动解决这一问题

    换句话说，机器学习模型是一个黑匣子，要消除偏见就要在数据集中把所有可能导致偏见的数据都删除掉，而这会耗费巨量的人力，往往是不可能的。对于传统的算法，人们还可以可以手动对程序逻辑进行修改；而对于机器学习，你没有办法劝说一个大模型改正自己的错误——它过于庞大，难以捉摸。（原文如下，不知道我的理解是否正确）

    > Algorithms are more likely to be implemented with no appeals process in place.

5. 算法往往被大规模地使用，这使得它们能够产生很大的影响
6. 出于经济、成本的原因，算法一经诞生就很容易被大公司所青睐  
7. 技术意味着权力，权力意味着更大的责任。


## 总结

- 数据伦理学很重要，不能忽视
- 算法可以形成反馈循环，有时候会带来意想不到的结果
- 由于算法本身的特点，算法的偏见比人的偏见更可怕
- 为了解决伦理问题，我们可以采取以下方法：
    - 分析自己负责的项目可能存在的伦理问题
    - 在公司中实践一些可以促进伦理的具体方法
    - 增加项目负责人员性别、族裔上的多样性
