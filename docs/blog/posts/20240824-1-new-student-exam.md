# 入学考试记

这是我参加 USTC 入学考试的感受和想法。

<!-- more -->

## 上午

上午第一场是英语考试。由于先前参加过雅思已经申请了 L4，这场英语考试压力不是很大，目的是测试自己的真实水平。考试难度比预想的大，听力、阅读比高考明显难，但比雅思简单。踩点完成了卷子，最后一篇阅读作答有些胡乱。这说明使用雅思托福申请 L4 赋分是明显高于这套卷子的分数的，难度上，雅思听力阅读的 8.5 小于这套卷子的 80。

第二场是计算机。这场考试是有点让人失望的，因为考试的题目较去年而言没有什么变化，前半部分比 CSP-S 初试要简单（除了最后一道多选题可能有点问题），C 语言的语法题非常刁钻，尤其是多选题，考察 OI 中几乎不会用到的指针和函数指针。考场上大部分同学都提前交卷（包括我），感觉可能因为成绩的随机波动被分入普通班。

## 下午

下午的数学考试从三点开始，题型比较类似中科大少年班/少创班的初选题，但难度高一些。填空题（8 道）往往用高考范围内知识点就可以解决，解答题（3 道）都是高考范围内的。整张卷子对我很有挑战性。最后整张卷子做完空了两道解答题（第一题和求 $n_{10}$ 的那题）估分：70 左右。

五点到七点的休息中我吃了晚饭并回宿舍洗了澡，洗了当天的衣服。

晚上的物理考试是当天最激动人心的一集，考试时间由七点到九点，对于像我这样武汉外校的学生来说，这场考试算是我参加过最晚的考试了。我（自认为）物理基础比数学基础弱。题型和数学差不多，都是三道解答题，但是分值不同。前一个小时做完了所有填空题，后面一个小时都用来磕第一道解答题了（可能有点亏），最终空了最后两道大题。估分：55 左右。

## 小结

中科大的入学考最有意思的在于考试的编排，最不耗思维的英语放在早上第一场，紧接着又是区分度最低的计算机。下午的数学和物理难度逐级递增，越来越刺激，有电影大片的激荡和心潮澎湃。

总的来说， 这场考试发挥的应该是自己的真实水平，很好的符合了考试的目的，对于没有怎么准备的我还是相当不错的但是计算机太没有区分度，有可能因为成绩的随机波动分到普通班。
